# Rugby Performance Tracker

A Java console application for recording and displaying rugby training sessions.

## Features

- Record athlete name

- Record training date

- Record session type

- Track session duration

- Track sprint time

- Track body weight

- Add training notes

- Add multiple training sessions

- Display complete training history

## Technologies Used

- Java

- Apache NetBeans

- ArrayList

- Scanner

- Git and GitHub

## Current Version

### Version 1

The program currently allows users to enter training information through the console and store multiple sessions during one run.

## Future Improvements

- Save training history after the program closes

- Add personal best sprint tracking

- Calculate total weekly training time

- Add a menu system

- Add data validation

- Create a graphical user interface

- Add charts and performance analytics
